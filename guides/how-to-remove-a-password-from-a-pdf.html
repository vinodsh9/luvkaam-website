How to remove the password from a PDF

You get a PDF every month with a password, and you are tired of typing it. Or you need to merge a locked file with others. If you know the password, you can save a copy with the lock removed.

An important limit

This tool needs the real password. It does not guess or break passwords. If you do not know it, ask the person or company that sent you the file. And only use the tool on files that belong to you or that you have permission to open.

Steps

  1. Open Unlock PDF.
  2. Choose the protected PDF.
  3. Type its password.
  4. Tick the box that says you own the PDF or have permission to remove its protection.
  5. Press Unlock file.
  6. Download the new copy. The original stays as it was.

It runs in your browser. The file and the password are not uploaded.

If the password is wrong

You will see a message that the password is not correct. Check the caps lock key, and check for a space at the end if you pasted it. Many banks use a password made from your name and date of birth, so read the email that came with the file.

A PDF with no password to open

Some PDFs open freely but block printing, copying or editing. In that case, leave the password box empty and tick the permission box. If the file has no protection at all, the tool says so.

After unlocking

Now the file can be used with the other tools: merge it, split it or copy its text.

Keep your files safe

An unlocked copy has no protection. If it holds private details, do not leave it in a shared folder. Delete it when you are done, or lock it again with Protect PDF using a password of your own choice.
