How to extract text from a scanned PDF

Updated 23 October 2026

A scanned PDF is a stack of page pictures, so the usual copy-and-paste does not work. To get the words out you need OCR, which reads each picture and returns text.

Step 1: confirm it is a scan

Try to select a line of text or search for a word. If neither works, the file is a scan. Our guide on scanned and text PDFs shows three quick tests. If the text does select, you do not need OCR. Use the PDF to Text steps instead.

Step 2: turn the pages into images

Luvkaam's Image to Text tool reads JPG, PNG and WEBP files, so each page must become an image first. Most PDF viewers can export pages as images. If yours cannot, open each page at full size and take a screenshot, then crop to the text.

Step 3: run OCR on each page

  1. Open the Image to Text tool.
  2. Choose the first page image and run the conversion.
  3. Copy the result into a document, then repeat for the next page.

Keeping pages in order as you go saves tidying up later.

Step 4: proofread

Scans are often crooked, faded or marked with stamps, so mistakes are more common than with screenshots. Compare names, dates and amounts against the original. Our tips on improving OCR accuracy can help if the first pass is poor.

Please note: Luvkaam does not yet read a scanned PDF in a single step, so this guide uses the page-by-page method. It works for a few pages at a time and is slow for long documents.
