How to extract text from a PDF online

Updated 23 October 2026

Sometimes you only need the words from a PDF: a few paragraphs for a report, a table of figures to check, or a policy to search. Extracting text is quick when the PDF is built the right way, and impossible when it is not.

Why some PDFs work and others do not

A PDF can hold real text, where each letter is stored as a character, or it can hold pictures of pages. A PDF exported from Word or a website has real text. A PDF made by scanning paper is usually just images. Tools can extract the first kind directly. The second kind needs OCR first. Our guide on scanned and text PDFs shows how to tell which you have.

Steps for a text PDF

  1. Open the PDF to Text tool on Luvkaam.
  2. Choose your PDF file.
  3. Run the extraction.
  4. Copy the text or save it to a file.

What to expect in the result

  • Plain text comes through well. Fonts, colours and page layout do not.
  • Tables may lose their columns and turn into lines of text, so check them before you rely on them.
  • Headers, footers and page numbers can appear in the middle of the text.
  • Text in two columns can come out in an odd order.

If you get nothing back

An empty result almost always means the PDF is a scan. Save each page as an image, then use the Image to Text tool on those pages.

Password-protected files

Some PDFs block copying. If you own the file or have permission to use its text, remove the restriction in the program that created it, then try again.
