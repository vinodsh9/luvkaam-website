Scanned PDF vs text PDF: how to tell the difference

Updated 23 October 2026

Two PDFs can look identical on screen and still be completely different inside. One holds real text you can select. The other holds photographs of pages. Knowing which you have saves time, because each needs a different approach.

Test 1: try to select text

Open the PDF and drag your cursor across a line of text. If the words highlight, it is a text PDF. If you highlight a whole block or nothing at all, it is a scan.

Test 2: search for a word

Press Ctrl+F (or Cmd+F on a Mac) and search for a word you can see on the page. A match means the PDF has real text. No match, for a word clearly on the page, means it is a scan.

Test 3: copy and paste

Select a paragraph, copy it and paste it into a notes app. Readable words mean a text PDF. Nothing, or strange symbols, point to a scan or to a file with a damaged text layer.

What to do with each

  • Text PDF: extract the words directly with the PDF to Text tool. Our PDF text guide has the steps.
  • Scanned PDF: save each page as an image and run it through image OCR. For a better scan next time, read how to improve OCR accuracy.

Mixed files

Some PDFs combine both: typed pages followed by scanned signatures or stamped pages. Run the tests on several pages, not just the first.

A quick clue: scanned PDFs are often much larger than a text PDF of the same length, because every page is stored as a picture.
