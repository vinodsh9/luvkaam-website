Frequently asked questions

Is Luvkaam free to use?

Luvkaam is designed to offer supported tools free after registration. The current prototype only implements some features; some tools are still being developed.

Which files can I process right now?

The current working demo supports JPG, PNG and WEBP image OCR and text extraction from PDFs containing selectable text, with a 10 MB file limit.

Can I convert a scanned PDF to Word?

Scanned PDF OCR and reliable PDF-to-Word output are not fully implemented in this prototype. Do not rely on those features until their tool pages show they are available.

Does Luvkaam store uploaded files?

The current image OCR and PDF text extraction run in your browser. AI text tasks send the text you submit to the selected AI provider through the backend. Review the privacy policy before using sensitive documents.

Do I need to register?

Yes, the planned free-access experience requires your name, email address and phone number. This prototype checks the format of those fields; SMS one-time-password verification is not yet connected.

How to extract text from an image with OCR

An image-to-text converter uses optical character recognition (OCR) to turn printed words in a clear photo into editable text. For better results, use a sharp JPG, PNG or WEBP image with good lighting, straight alignment and readable text.

How to extract text from a PDF

A PDF-to-text converter can extract words from a PDF that contains selectable text. If the PDF consists of scanned page images, OCR is needed before its text can be selected; scanned-PDF OCR is not enabled here yet.

PDF converters and common file formats

Choose a file converter based on your goal: JPG for images, PDF for consistent sharing and printing, or an editable document format when you need to change text. Check each tool’s status before starting, because not every conversion is available yet.

Free online PDF tools and image-to-text OCR

Image to text OCR online

Use an online image-to-text converter to turn clear JPG, PNG or WEBP images into editable text. This OCR tool is useful for screenshots, printed notes, forms and photographed pages. For best results, use a sharp image with good lighting and readable text.

PDF to text converter

Use the PDF-to-text converter to extract text from a text-based PDF when you need to copy, search or reuse its contents. Scanned PDFs that contain only page images need OCR; scanned-PDF OCR is not enabled in this version.

Free online PDF tools

Luvkaam brings common online document tools into one place. Image-to-text OCR and selectable PDF text extraction are available now. Merge PDF, compress PDF, PDF to Word and image-to-PDF conversion are planned features and are not currently available.

Popular document tasks

Practical guidance for image text extraction and PDF text conversion.

Turn a photo into text

Need to copy words from a screenshot, printed page or phone photo? Use the image-to-text converter to recognise readable text in JPG, PNG or WEBP images. This OCR workflow can help with class notes, receipts and everyday paperwork. Always check the extracted text for mistakes.

Extract text from a PDF online

A PDF text extractor works when the PDF contains selectable text. It can help you reuse passages in notes, search for a phrase or copy text into another document. If the PDF is a scan, you will need a scanned-PDF OCR tool; that feature is not available yet on Luvkaam.

Choose the right PDF converter

PDF converters serve different needs: PDF to JPG can make page images, JPG to PDF can combine images into a document, and PDF to Word can support editing. Luvkaam is adding conversion tools in stages. Use only features marked as available, and do not rely on planned tools until they are implemented.
