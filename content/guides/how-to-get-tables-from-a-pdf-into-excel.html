title: How to Get Tables From a PDF Into Excel h1: How to get tables from a PDF into Excel desc: Move simple tables from a PDF into an Excel or CSV file. What works, what does not, and how to check the result. tools: pdf-to-excel, pdf-to-text

Bank statements, price lists and result sheets often arrive as PDFs. Typing the numbers into Excel is slow and easy to get wrong. This tool reads the rows of a PDF table and gives you a spreadsheet.

Steps

  1. Open PDF to Excel.
  2. Choose a PDF with a table in it. It must contain real text, not a scan.
  3. Choose the layout: one sheet per page or all pages on one sheet.
  4. Press Extract tables.
  5. Download the .xlsx file for Excel, or the .csv file for any spreadsheet app.

The PDF is read on your device and is not uploaded.

Which layout should you pick?

Use one sheet per page when each page stands on its own, like separate months of a statement. Use all pages on one sheet when it is one long table that happens to continue across pages. Then you can sort and filter it as one list.

This is a best guess

A PDF does not store a table the way Excel does. It only knows where each word sits on the page. The tool looks at that spacing to guess the rows and columns. Simple grids work well. These can go wrong:

  • Cells that span several columns or rows.
  • Tables with no clear gaps between columns.
  • Text that wraps onto a second line inside a cell.
  • Pages with several small tables, or a table next to a paragraph.

Check before you use the numbers

Always do three quick checks. Do the totals still match the PDF? Is any column shifted so that a number sits under the wrong heading? Are dates and amounts still readable as dates and amounts? Money matters deserve this minute.

If nothing is found

You will see a message that no selectable text was found. The PDF is a scan. Run OCR scanned PDF, then retype or paste the figures into your sheet. Scanned tables are hard for any tool, so expect to fix some by hand.

A small trick

If a table comes out messy, extract the plain text with PDF to text. Sometimes the text version is easier to paste in and split into columns using Excel's "Text to Columns".
