You have three PDFs: an application form, an ID proof and a bank statement. The website wants one file. Or you scanned a document in parts and now need it in one piece. This is what merging is for, and it takes about a minute.

Merge PDFs with Luvkaam

  1. Open the Merge PDF page.
  2. Tap Choose files and pick two or more PDFs. On a computer you can also drag them onto the page.
  3. Look at the list. The first file in the list becomes the first pages of the new PDF. Use the arrows next to a file to move it up or down.
  4. Press Merge files.
  5. Press Download PDF. The new file is called merged.pdf.

That is all. The files are joined inside your browser. They are not sent to a server, so a bank statement or an ID card stays on your phone or laptop.

Get the order right before you merge

People often merge first and notice the wrong order later. Check the list once before you press the button. If you need page 3 of one file to sit before page 1 of another, merging alone will not do it. Split the file first with Split PDF, then merge the parts in the order you want.

Things that can go wrong

"Could not be read as a PDF"

The file may be damaged, or it may not really be a PDF. Try opening it in your phone's PDF viewer first. If it opens there, save it again from the viewer and try once more.

The file asks for a password

A password-protected PDF cannot be merged straight away. Remove the password first with Unlock PDF. You will need to know the password. Only do this for files that belong to you.

The files are too big

Each file can be up to 25 MB. If one is bigger, make it smaller with Compress PDF and then merge.

The merged file is too large to email

Merging adds the sizes together. Most email services stop at around 20 to 25 MB. Compress the final file, or compress each part before you merge.

Tips for a clean result

  • Rename your files with numbers, like 1-form.pdf and 2-id.pdf. You will see the order at a glance.
  • Pages of different sizes stay as they are. A photo-sized page and an A4 page will sit together in the same PDF.
  • Keep the original files until you have opened the merged PDF and checked every page.
  • If your documents are photos rather than PDFs, turn them into a PDF first with JPG to PDF.

Does it cost anything?

No. You can merge up to three times a day without registering. A free registration removes that daily limit and unlocks the other tools.

A quick check before you send

Open the merged PDF and scroll through it once. Look at the first and last page of each part. Make sure nothing is upside down. If a page is turned the wrong way, fix it with Rotate PDF. It takes seconds and saves you from sending a document that looks careless.
